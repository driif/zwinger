---
name: grilling
description: Use when the user wants to test a plan or design before you build it, or says "grill me". Ask the user questions one at a time until you and the user have the same understanding.
---

Ask me questions about all parts of this plan until we have the same understanding.
Examine each branch of the design tree.
Resolve the dependencies between decisions one at a time.
For each question, give your recommended answer.

Ask one question at a time. Wait for my answer before you ask the next question.
Do not ask more than one question at a time.

If you can find a *fact* in the codebase, find it there. Do not ask me.
I make the *decisions*. Ask me about each decision and wait for my answer.

Do not start to do the plan until I confirm that we have the same understanding.
